# Скільки реально триває закупівля БпЛА і РЕБ у Prozorro

Фінальний проєкт курсу **MilTech Data Analytics** (Choice31 × IAMPM), кейс 1 **Supply Chain & Logistics**.
Автор: Андрій Килимник.

**Головне питання кейсу:** скільки часу реально йде від заявки до отримання і чого чекати наступного разу?

## Відповідь

Шлях «оголошення закупівлі → договір», Prozorro 2022–2025, n = 9 298:

| Шлях закупівлі | Зазвичай (медіана) | Закласти в план (P80) | Довгий випадок (P90) |
|---|---|---|---|
| БпЛА, каталог Prozorro Market | 9 днів | **13 днів** | 16 днів |
| БпЛА, відкриті торги | 20 днів | **25 днів** | 28 днів |
| РЕБ, відкриті торги | 21 день | **27 днів** | 29 днів |
| Нові відкриті торги (з 15.07.2026) | не менше ~21 (закон) | **~28 (оцінка)** | даних ще немає |

- Каталог удвічі швидший за відкриті торги; для РЕБ каталогу немає.
- З 2023 року цикл стабільний, тож на історичні дані можна спиратися.
- Регіон замовника строк майже не змінює (виняток: м. Київ).
- З 15.07.2026 мінімальний строк подання пропозицій у відкритих торгах 15 днів замість 7 (постанова КМУ № 1178, п. 34), тому для нових торгів історичні 25 днів замало.
- Обмеження: лише до підписання договору, фактичної поставки в даних немає; 39% закупівель БпЛА і РЕБ іде без тендеру і не має дати оголошення.

## Дані

- [Prozorro Ukraine Procurement 2022–2025](https://www.kaggle.com/datasets/romankachmar/prozorro-ukraine-procurement-2022-2025) (Kaggle, CC0): 12 877 960 завершених тендерів. Опис набору: `KAGGLE_DATASET_README.md`, `DATA_DICTIONARY.md`.
- Публічне API Prozorro: `https://public-api.prozorro.gov.ua/api/2.5/tenders/{id}` (дата договору, назви закупівель).
- Сирі дані (~5 ГБ) у репозиторій не входять. Щоб відтворити: завантажити CSV з Kaggle в `data/raw/`.

## Структура

```
notebooks/
  01_explore.ipynb        огляд сирих даних
  02_filter.ipynb         відбір за CPV-кодами → candidates.parquet (15 532)
  03_clean_metrics.ipynb  очищення, тривалість етапів → clean.parquet (9 305)
  04_api_enrich.ipynb     level up: API Prozorro, дата договору → final.parquet
  05_analysis.ipynb       аналіз, точність фільтра, графіки 1–3
  06_regions.ipynb        регіональні відмінності, графік 4
data/processed/           проміжні й фінальні таблиці (Parquet, CSV для дашборду, Excel з ручною перевіркою)
screenshots/              графіки і скриншоти кожного кроку (журнал доказів)
```

## Як запустити

```bash
pip install -r requirements.txt
jupyter notebook   # ноутбуки виконувати по порядку з папки notebooks/
```

Ноутбуки 01–03 потребують сирих CSV у `data/raw/`; 05–06 працюють з `data/processed/`, які вже є в репозиторії.
